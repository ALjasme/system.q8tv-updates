# system.q8tv · التحديثات والإعدادات المشتركة

هذا المستودع لا يحوي الكود، بل ثلاثة أشياء تقرؤها شاشات system.q8tv في البيت:

- **latest.json**: آخر نسخة من الواجهة وشاشة التوقف، ورابط تنزيلها وبصمتها (SHA-256).
- **الإصدارات (Releases)**: ملفات APK نفسها. أندرويد لا يقبل تحديثًا إلا إذا كان موقّعًا بنفس مفتاح النسخة المثبتة.
- **settings.json**: خيارات «تخصيص» للأجهزة الثلاثة مرة واحدة.

## تعديل الإعدادات من الجوال
افتح `settings.json` في تطبيق GitHub أو الموقع ← تعديل ← غيّر القيم ← **زِد رقم `rev` بواحد** ← حفظ.
تصل التعديلات للأجهزة خلال ٣٠ دقيقة. أي تغيير يدوي على تلفاز يبقى حتى التعديل التالي هنا.

| المفتاح | المعنى | القيم |
|---|---|---|
| live_sky | النافذة الحية | true / false |
| occasions | المناسبات التلقائية | true / false |
| satellite | خريطة القمر الصناعي | true / false |
| moon / planes / goals | القمر، الطائرات، احتفال الأهداف | true / false |
| hazards | تنبيه الطقس الخطر | true / false |
| quakes | الزلازل | true / false |
| sirens | صافرات الإنذار من الأخبار | true / false |
| breaking | الأخبار العاجلة المهمة جدًا | true / false |
| markets | حركة الذهب والعملات | true / false |
| sea / seasons / adhkar / met_text | البحر، المواسم، الأذكار، نص الأرصاد | true / false |
| hadith_minutes | مدة الحديث والآية | 10, 15, 20, 30, 60 |
| stocks_seconds | مدة بطاقات الأسهم | 10, 15, 20, 30, 45 |
| stock_markets | الأسواق | ["kw","us","sa","ae","qa","bh"] |

مثال:
```json
{"rev": 2, "set": {"hadith_minutes": 30, "planes": false, "stock_markets": ["kw", "us", "sa"]}}
```
